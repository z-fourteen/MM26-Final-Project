# 相机位姿结果展示任务规划

本文档用于落实“数码相机定位”这一作业重点的结果展示方案。当前 SfM 与 VGGT 流水线已经能够估计或预测相机位姿，但报告中需要把该能力转化为明确、可检查、可复现的结果证据。

## 1. 展示目标

作业要求的核心输出包括：

- 手机相机的定位结果；
- 被拍物体或场景的三维点坐标；
- 能说明输入图像、相机位姿、三维结构之间关系的可视化结果。

因此最终报告中不应只展示点云或 3DGS 渲染图，还应显式展示相机位姿。推荐采用“静态报告图为主，GUI/交互查看为辅”的方式。

## 2. 最终交付物

建议最终产出以下文件或结果：

1. 相机位姿可视化图
   - 内容：稀疏点云或 VGGT 点云 + 每张图像对应的相机中心/视锥。
   - 用途：放入报告正文，直接证明系统输出了相机定位。
   - 建议路径：`report/figures/camera_pose_sfm.png`、`report/figures/camera_pose_vggt.png`。

2. SfM 与 VGGT 相机轨迹对比图
   - 内容：同一场景下两种方法估计的相机轨迹，使用不同颜色区分。
   - 用途：展示传统几何方法和学习方法在相机定位任务上的结果差异。
   - 建议路径：`report/figures/camera_pose_comparison.png`。

3. 相机位姿统计表
   - 内容：输入图像数、成功注册/预测相机数、是否输出内参、是否输出外参、平均重投影误差等。
   - 用途：给报告提供定量支撑。
   - 建议路径：可直接写入 `report/main.tex`，或先保存为 `outputs/<scene>/camera_pose_summary.md`。

4. 可复现实验说明
   - 内容：说明位姿文件来源、坐标系含义、可视化脚本命令。
   - 用途：便于答辩或检查时复现。
   - 建议路径：补充到 `docs/artifacts_manifest.md` 或实验手册中。

## 3. 是否需要 GUI 展示

不建议把 GUI 作为主要结果形式。

GUI 或 3D viewer 的价值在于交互检查，例如旋转点云、查看相机分布是否合理、确认某些相机是否离群。但报告评审通常更需要稳定的静态图和明确表格。因此：

- 报告正文必须有静态相机位姿图；
- GUI 可作为附加演示工具；
- 如果时间有限，优先实现静态导出图，而不是开发复杂 GUI。

## 4. 具体任务规划

### 任务 A：确认 SfM 相机位姿输出

目标：明确 SfM 流水线已经输出哪些相机参数，并确认可以从中计算相机中心。

操作步骤：

1. 检查 SfM 输出目录。
   - 重点查看是否存在 COLMAP 格式文件，例如 `cameras.txt`、`images.txt`、`points3D.txt`，或二进制版本 `cameras.bin`、`images.bin`、`points3D.bin`。
   - 若项目使用自定义 checkpoint，也需要确认其中是否保存了每张图像的旋转和平移。

2. 提取每张图像的外参。
   - 对 COLMAP 格式，`images.txt` 中通常包含四元数 `qvec` 和平移 `tvec`。
   - 相机中心可由外参计算：

```text
C = -R^T t
```

3. 导出 SfM 相机位姿表。
   - 建议字段：
     - `image_name`
     - `camera_id`
     - `qw, qx, qy, qz`
     - `tx, ty, tz`
     - `cx, cy, cz`
     - `registered`

4. 生成 SfM 相机位姿图。
   - 背景显示 SfM 稀疏点云；
   - 每个相机位置画一个点或小坐标轴；
   - 关键场景可以额外画相机视锥；
   - 图题建议为“传统 SfM 恢复的相机位姿与稀疏点云”。

### 任务 B：确认 VGGT 相机位姿输出

目标：明确 VGGT 推理结果中的相机参数，并将其转换成可报告展示的形式。

操作步骤：

1. 检查 VGGT 输出目录。
   - 重点查看推理脚本 `src/tools/run_vggt_inference.py` 产生的文件。
   - 常见输出可能包括相机外参、内参、深度图、点云或 3DGS 初始化数据。

2. 统一位姿表示。
   - 若 VGGT 输出的是 camera-to-world 矩阵，则相机中心通常为矩阵的平移列；
   - 若输出的是 world-to-camera 矩阵，则需要按 `C = -R^T t` 转换；
   - 在报告中需要说明使用的是哪一种约定。

3. 导出 VGGT 相机位姿表。
   - 建议字段：
     - `image_name`
     - `fx, fy, cx, cy`
     - `camera_center_x, camera_center_y, camera_center_z`
     - `pose_matrix`

4. 生成 VGGT 相机位姿图。
   - 背景显示 VGGT 预测点云或由深度反投影得到的点云；
   - 相机位置用与 SfM 不同的颜色；
   - 图题建议为“VGGT 预测的相机位姿与三维结构”。

### 任务 C：生成 SfM/VGGT 对比图

目标：在同一视觉表达下对比两种方法的相机定位结果。

操作步骤：

1. 选择同一个场景作为主展示对象。
   - 优先选择图像覆盖较完整、点云结构清晰、相机轨迹不退化的场景；
   - 如果真实手机拍摄数据已经准备好，优先使用手机拍摄数据；
   - 如果手机数据不稳定，可使用已跑通的公开场景作为补充。

2. 对齐坐标尺度。
   - SfM 通常存在尺度不确定性；
   - VGGT 输出也可能处于归一化尺度；
   - 若只展示轨迹形状，可以在图注中说明“为便于可视化，轨迹已做尺度归一化”；
   - 若进行数值比较，需要先做相似变换对齐。

3. 绘制对比图。
   - SfM 相机中心：蓝色；
   - VGGT 相机中心：橙色；
   - 点云：灰色；
   - 可选：用线连接相机中心形成拍摄轨迹；
   - 可选：标注首帧、末帧和少量关键帧编号。

4. 在报告中解释差异。
   - SfM 更依赖特征匹配和多视图几何；
   - VGGT 可以直接预测相机参数和几何结构；
   - 若二者轨迹趋势一致，可说明结果相互印证；
   - 若局部存在偏差，可从纹理不足、视角变化、尺度归一化或匹配失败角度分析。

### 任务 D：补充报告内容

目标：让报告明确回应作业要求中的“手机相机定位”。

建议在 `report/main.tex` 中增加一个小节，例如：

```latex
\subsection{相机位姿估计结果}
```

该小节建议包含：

1. 方法说明
   - SfM：通过特征匹配、PnP 注册、三角化和 Bundle Adjustment 获得相机外参与稀疏点云；
   - VGGT：通过前馈网络预测相机参数、深度/点云，并进一步用于 3DGS 初始化。

2. 结果图
   - 插入 SfM 相机位姿图；
   - 插入 VGGT 相机位姿图；
   - 若篇幅允许，插入对比图。

3. 定量表
   - 列出注册/预测相机数量；
   - 列出 SfM 的平均重投影误差；
   - 若有 VGGT 的有效帧数或置信度，也一并列出。

4. 结论表述
   - 明确写出“本系统输出了每张输入图像对应的相机位姿”；
   - 明确写出“三维点云与相机视锥位于统一世界坐标系中”。

可使用如下报告表述：

```text
图 X 展示了重建点云与相机视锥在同一世界坐标系下的分布。每个视锥对应一张输入图像的相机位姿，其空间分布与绕物体拍摄的采集过程一致，说明系统不仅恢复了三维结构，也完成了输入相机的定位。SfM 方法通过多视图几何优化得到相机外参，VGGT 方法则直接预测相机参数和三维结构，两者均可作为数码相机定位任务的输出。
```

## 5. 推荐实现顺序

1. 先完成 SfM 位姿导出与可视化。
   - 原因：SfM 的相机外参定义清晰，容易解释，也更符合课程第 4 章的传统几何内容。

2. 再完成 VGGT 位姿导出与可视化。
   - 原因：VGGT 可作为学习式方法对照，展示项目扩展性。

3. 最后做对比图和报告小节。
   - 原因：只有两边的输出都统一成相机中心/视锥后，对比图才有意义。

## 6. 建议脚本形态

可以新增一个统一脚本：

```text
src/tools/visualize_camera_poses.py
```

建议支持参数：

```text
--sfm-model outputs/<scene>/sfm/...
--vggt-output outputs/<scene>/vggt/...
--points outputs/<scene>/...
--output report/figures/camera_pose_comparison.png
--mode sfm|vggt|compare
--normalize-scale
--show-frustums
```

脚本职责：

- 读取 SfM/VGGT 相机位姿；
- 计算相机中心；
- 可选读取点云；
- 绘制点云、相机中心、视锥和轨迹；
- 保存报告可直接引用的 PNG/PDF。

## 7. 验收标准

完成后应满足：

- 报告中至少有一张图明确展示相机位置；
- 图中相机位置与三维点云处于同一坐标系；
- 图注明确说明颜色、相机视锥和点云含义；
- 文中明确说明 SfM/VGGT 分别如何获得相机位姿；
- 至少有一张表统计相机定位结果；
- artifact 文档中说明位姿文件和可视化图的生成位置。

## 8. 最低可交付版本

如果时间紧，最低版本可以只完成以下三项：

1. 从 SfM 输出中导出相机中心；
2. 画一张“稀疏点云 + 相机中心/视锥”的 PNG；
3. 在报告中增加一段文字说明该图对应手机相机定位结果。

这样已经能直接回应作业要求。VGGT 对比图和 GUI 展示可以作为增强项。
