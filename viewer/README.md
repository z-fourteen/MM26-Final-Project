# 3DGS Camera Pose Viewer

Gradio hosts the upload and preset-selection UI. An embedded Three.js viewer
renders one Graphdeco-compatible Gaussian PLY at a time together with that
result's camera centers, trajectory, and camera frustums.

## Launch

From the repository root:

```bash
python -m viewer.app --host 0.0.0.0 --port 7860
```

Then open `http://127.0.0.1:7860` locally, or the corresponding server address.

Preset metadata and camera files live under:

```text
viewer/examples/<example>/
  scene.json
  cameras.json
  point_cloud.ply  # ignored large asset
```

Prepare the ignored PLY assets from existing local outputs:

```bash
python -m viewer.prepare_examples --mode symlink
```

See `viewer/examples/README.md` for collaboration and custom source paths.

## Inputs

- Gaussian PLY generated by Graphdeco 3D Gaussian Splatting.
- Optional camera file:
  - Graphdeco `cameras.json`.
  - VGGT JSON containing `world_from_camera_3x4`.
  - CSV containing `camera_center_world_x/y/z` or `x/y/z`.
  - COLMAP `images.txt`.

CSV files with camera centers only can display positions and trajectories, but
not orientation frustums or camera-view navigation.

Selecting a camera, or using the previous/next buttons, immediately moves the
WebGL rendering view to that camera pose. The explicit camera-view button can
be used to return to the selected pose after manually orbiting the scene.
